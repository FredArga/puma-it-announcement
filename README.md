# PUMA IT Recruitment Announcement

Official announcement website for the PUMA IT 2026 recruitment results.

## About

This website was created to provide the final recruitment announcement for PUMA IT.

Users can enter their registered name to check their selection result.

## Features

- Search participant name
- Display selection status
- Display division
- Display position
- Responsive design
- Simple user interface

- CSS
